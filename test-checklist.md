# Ручная проверка Linkdrop

Отмечай `[x]` — работает, `[!]` — не работает (рядом пару слов: что ввёл, что увидел, что ждал).

Запуск локально: `cd backend && npm run dev` и `cd frontend && npm run dev` → http://localhost:5173

---

## Сайт

### 1. Ссылки разных видов → карточка с превью, названием, длительностью и форматами
- [ ] YouTube `youtube.com/watch?v=…`
- [ ] YouTube `youtu.be/…`
- [ ] YouTube Shorts `youtube.com/shorts/…`
- [ ] YouTube мобильная `m.youtube.com/…`
- [ ] YouTube с таймкодом `…&t=30s`
- [ ] TikTok полная `tiktok.com/@user/video/…`
- [ ] TikTok короткая из приложения `vm.tiktok.com/…`
- [ ] Instagram reel — **ожидаемо ошибка**, пока нет cookies технического аккаунта

### 2. Ввод
- [ ] Текст вокруг ссылки: `Смотри! https://vm.tiktok.com/… круто` → находит видео
- [ ] Без https: `youtube.com/watch?v=…` → находит видео
- [ ] Точка или скобка в конце: `https://youtu.be/….` → находит видео
- [ ] Просто слово `привет` → «Не вижу ссылки…»
- [ ] Пустое поле → кнопка неактивна
- [ ] Кнопка «Вставить» подставляет ссылку из буфера

### 3. Форматы → файл скачивается, открывается, есть звук
- [ ] MP4 1080p
- [ ] MP4 720p
- [ ] MP4 480p
- [ ] MP3
- [ ] Название с кириллицей и эмодзи → нормальное имя файла
- [ ] Размер в карточке (~N МБ) примерно совпадает с реальным
- [ ] Полоса прогресса двигается, проценты растут

### 4. Ошибки → понятный текст, а не «что-то пошло не так»
- [ ] Чужой сайт (vk.com, rutube) → «Поддерживаются только YouTube, Instagram и TikTok»
- [ ] Приватное или удалённое видео
- [ ] Плейлист, канал или профиль → «пришлите ссылку на одно видео»
- [ ] Видео длиннее 60 минут → «Видео длиннее 60 минут»
- [ ] Прямой эфир → «Прямые эфиры не поддерживаются»

### 5. Сценарии
- [ ] Отмена во время подготовки → возврат к выбору формата
- [ ] Отмена и **сразу** «Скачать» другой формат → загрузка начинается (не «уже идёт загрузка»)
- [ ] Две вкладки одновременно качают → вторая получает «У вас уже идёт загрузка»
- [ ] Закрыть вкладку во время подготовки, открыть заново → можно качать
- [ ] После готового файла: «Другой формат» → можно выбрать и скачать ещё
- [ ] После готового файла: «Скачать другое видео» → чистая форма
- [ ] Ссылка «Скачать файл» на экране готовности работает
- [ ] Много раз подряд «Найти видео» (20+ за минуту) → «Слишком много запросов»

### 6. Браузеры и устройства
- [ ] Chrome на компьютере
- [ ] Safari на Mac
- [ ] Safari на iPhone — файл скачивается сам? если нет, работает ли «Скачать файл»?
- [ ] Chrome на Android
- [ ] Узкий экран (360–390 px): всё влезает, нет горизонтальной прокрутки
- [ ] Медленный интернет / обрыв связи посередине → понятная ошибка, можно повторить

## Бот в MAX

Нужно: токен и секрет в `backend/.env`, сервер на https, `npm run max:subscribe`.

### 1. Старт
- [ ] Кнопка «Начать» → приветствие
- [ ] Команда `/start` → приветствие

### 2. Как приходит ссылка → бот пишет «Скачиваю…», затем присылает видео
- [ ] Ссылка обычным сообщением
- [ ] Ссылка с текстом вокруг и точкой в конце
- [ ] Пересланное сообщение со ссылкой (из другого чата)
- [ ] Ответ (reply) на сообщение со ссылкой
- [ ] Текст-гиперссылка (слово, за которым спрятана ссылка)
- [ ] «Поделиться» из приложения YouTube в MAX
- [ ] «Поделиться» из приложения TikTok в MAX
- [ ] Instagram — **ожидаемо ошибка** без cookies

### 3. Видео в MAX
- [ ] YouTube-видео воспроизводится прямо в чате
- [ ] TikTok-видео воспроизводится в чате (оно в HEVC — на старых Android может не играть)
- [ ] Видео больше 250 МБ приходит файлом, а не видео
- [ ] Короткое и длинное (10–30 мин) видео — сколько ждать ответа

### 4. Ошибки и лимиты
- [ ] Сообщение без ссылки → «Не вижу ссылки…»
- [ ] Ссылка на чужой сайт → «Поддерживаются только YouTube, Instagram и TikTok»
- [ ] Две ссылки подряд, не дожидаясь первой → на вторую «Предыдущее видео ещё скачивается»
- [ ] Приватное или удалённое видео → понятный текст

### 5. Группа
- [ ] Добавить бота в групповой чат
- [ ] Обычные сообщения в группе → бот молчит
- [ ] Ссылка в группе → бот присылает видео (если не реагирует — возможно, MAX отдаёт боту в группе только упоминания; напиши)
